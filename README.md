## 03 / MY WAY OF THINKING

<div align="center">

### PROBLEM → STRATEGY → ARCHITECTURE → BUILD → GROW

</div>

I believe the best developers don't start with code.

They start with questions.

> What problem are we solving?

> Who actually needs this?

> Does the business model make sense?

> Can this solution scale?

> And most importantly, should we build it at all?

**Build the right thing before building the thing right.**
